# UNA VITA

Gioco narrativo/psicologico web in cui il giocatore attraversa una vita dall'infanzia alla vecchiaia. Le decisioni modificano tratti psicologici nascosti, relazioni e conseguenze future.

## Prima versione
- interfaccia responsive per telefono e PC;
- eventi narrativi divisi per età;
- scelte con conseguenze psicologiche nascoste;
- memoria delle scelte;
- avanzamento dell'età;
- età della morte variabile;
- riepilogo finale della vita;
- salvataggio locale sul dispositivo.

## Pubblicazione
Il progetto è predisposto per GitHub Pages tramite il workflow in `.github/workflows/pages.yml`.

URL previsto:
`https://ionut290.github.io/Una-Vita/`

Per la prima attivazione: GitHub > Settings > Pages > Build and deployment > Source > GitHub Actions.

## Struttura
- `index.html` interfaccia
- `style.css` grafica
- `events.js` database narrativo
- `app.js` motore di gioco

Il progetto è separato da Varga Gestionale e Varga Cantieri.
